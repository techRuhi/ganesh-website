# 🌐 Lord Ganesha – A Divine Website

A responsive single-page website dedicated to Lord Ganesha, showcasing his significance, festivals, temples, and spiritual traditions.

## 👩‍💻 About the Project
A frontend project created to showcase Lord Ganesha through an elegant design, attractive imagery, and responsive layouts.

## ✨ Features
- Responsive navigation
- Divine hero section
- Significance of Lord Ganesha
- Festival and temple sections
- Divine image gallery
- Modern and responsive UI

## 🛠️ Tech Stack
- HTML5
- CSS
- Bootstrap 5
- Font Awesome
- Google Fonts
